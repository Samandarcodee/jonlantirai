## 💡 Pro Tips

### For Generation:
1. Write in **English** for best results
2. Mention **style** explicitly
3. Be **specific** but concise
4. Add **quality** keywords (4K, HD)
5. Describe **mood** and **atmosphere**

### For Editing:
1. Use **clear, high-quality** images
2. **One change** at a time
3. Be **specific** about what to change
4. Use **simple** English
5. **Don't request** face changes (auto-preserved)

## ❌ Common Mistakes to Avoid

### Don't:

- ❌ Write long, complex instructions
- ❌ Expect instant results (takes 30-60 sec)

### Do:
- ✅ Be clear and specific
- ✅ Use English when possible
- ✅ One change at a time
- ✅ High-quality source images
- ✅ Wait patiently for results

## 📝 Prompt Templates

### Generation:
```
[Style] [subject] [action/pose], [environment], 
[lighting/mood], [quality/detail]

Examples:
"Realistic woman reading book, cozy library, warm lighting, 4K"
"Cartoon robot dancing, futuristic city, vibrant colors"
```

### Editing:
```
[Action] [what] [where/how]

Examples:
"Add mountains background"
"Change style to cartoon"
"Remove background people"
```

## 🆘 Troubleshooting

**Problem:** Image doesn't generate
- **Solution:** Make prompt more specific, try English

**Problem:** Edit doesn't work
- **Solution:** Simplify instruction, one change at a time

**Problem:** Low quality output
- **Solution:** Add "4K" or "high quality" to prompt

**Problem:** Takes too long
- **Solution:** Normal! Wait 30-60 seconds
